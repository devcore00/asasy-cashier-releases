# Asasy Kasher — أساسي كاشير

نظام نقاط البيع لأجهزة ويندوز. الريبو ده فيه **ملفات التثبيت بس**.

## ⬇️ تحميل آخر إصدار

**[تحميل Asasy Kasher](https://github.com/devcore00/asasy-kasher-releases/releases/latest)**

من صفحة الإصدار نزّل الملف اللي اسمه `Asasy-Kasher-Setup-<رقم الإصدار>.exe`.

## 💻 المتطلبات
- Windows 10 أو Windows 11 (64-bit)
- مساحة فاضية حوالي 600 ميجا

## 🛠️ التثبيت
1. شغّل ملف التثبيت.
2. لو ظهرت رسالة **"Windows protected your PC"**، اضغط **More info**، وبعدين **Run anyway**.
3. كمّل خطوات التثبيت. البرنامج هيتعمل له اختصار على سطح المكتب وفي قائمة ابدأ.
4. أول ما يفتح، هيطلب **كود التفعيل**. انسخ **رقم الجهاز** اللي ظاهر وابعته للدعم الفني، وهيوصلك الكود.

## 🔄 التحديثات
البرنامج بيتحدّث لوحده:
- لما تفتحه، بيدوّر على إصدار جديد وينزّله في الخلفية.
- بعد ما يخلص التنزيل بيظهر إشعار، والتحديث بيتثبّت لما تقفل البرنامج.
- **بياناتك مابتتأثرش بالتحديث**: المبيعات والمنتجات والصور والتفعيل كلهم بيفضلوا زي ما هم.

## 💾 بياناتك
بيانات البرنامج محفوظة على جهازك في:
```
%APPDATA%\AsasyKasher
```
- **ماتمسحش الفولدر ده.** فيه قاعدة البيانات والتفعيل.
- لو هتعمل نسخة احتياطية، انسخ الفولدر ده كله وانت قافل البرنامج.
- إلغاء تثبيت البرنامج **مابيمسحش** البيانات دي.
